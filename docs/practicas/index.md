## Normas de entrega

- Todas las prácticas se hacen en la **máquina virtual** del Tema 1, nunca en el equipo del aula.
- Se entrega **una memoria en PDF** por práctica, con el nombre que indica cada enunciado (`UT3_PN_Apellido_Nombre.pdf`).
- Para **cada ejercicio**, la memoria debe incluir:
    1. El **comando** o comandos, escritos como texto (para que se puedan copiar).
    2. Una **captura** del resultado en la que se vea el *prompt* con **tu usuario**.
    3. La **respuesta razonada** cuando el ejercicio hace una pregunta.
- Las capturas sin el *prompt* visible o con el usuario de otra persona no se tendrán en cuenta.
- Los apuntes tienen ejercicios resueltos para practicar. Las prácticas son **distintas**: no te limites a copiar comandos de los apuntes, entiende lo que hacen.
